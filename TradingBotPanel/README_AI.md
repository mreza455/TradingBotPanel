## ۱. هدف اولیه پروژه

### 🎯 درخواست اصلی کاربر:
ساخت یک پنل کنترل یکپارچه ویندوز برای:
- مدیریت متمرکز تمام ابزارهای هوش مصنوعی
- توسعه خودکار ربات‌های ترید (MT5 و TradingView)
- گرفتن پرامپت از کاربر و تحویل پروژه کامل بدون نقص

### 💡 معماری پیشنهادی: **Multi-Agent Organization**
سیستم به شکل یک سازمان طراحی شد که در آن:
- **رئیس (Chief Agent):** ChatGPT (مدیر تیم و معمار ارشد)
- **کارمندان (Workers):** ۱۳ ایجنت تخصصی دیگر
- **نظارت انسانی (Human-in-the-Loop):** کاربر در نقاط کلیدی تصمیم‌گیری

## ۲. پیش‌نیازهای فنی

### 🐍 نرم‌افزارها:
- **Python 3.10 یا بالاتر** (نسخه ۳.۱۲ توصیه می‌شود)
- **Windows 10/11**
- **MetaTrader 5** (برای تست ربات)

### 📦 کتابخانه‌های پایتون:
```bash
pip install PyQt5 requests pyyaml psutil
```

### ⚠️ چالش نصب:
- در نسخه Python 3.15، PyQt5 نصب نمی‌شد (نیاز به Visual C++ Build Tools داشت)
- **راه‌حل:** استفاده از دستور:
```bash
python -m pip install --only-binary=:all: PyQt5 requests pyyaml psutil
```

### 🔧 ساخت فایل EXE:
```bash
pip install pyinstaller
pyinstaller --noconsole --onefile trading_bot_panel.py
```

## ۶. قابلیت‌های هوشمند سیستم

### 🧠 ۱. مرحله تصویب پرامپت (Human-in-the-Loop):
قبل از هر کار، مدیر تیم (ChatGPT) پرامپت خام کاربر را دریافت می‌کند و پارامترهای زیر را اضافه می‌کند:

**پارامترهای اضافه شده به صورت خودکار:**
```
🎯 مدیریت سرمایه:
  - ریسک ثابت: ۲٪ از اکوئیتی
  - حداکثر دراودان: ۱۵٪

🛡️ مدیریت ریسک:
  - حد ضرر: داینامیک ATR
  - حد سود: R:R = 1:2
  - Break Even: در ۵۰٪ مسیر TP
  - Trailing Stop: 15 پیپ

⏱️ زمان‌بندی:
  - تایم‌فریم: H1
  - فیلتر اخبار High Impact

💱 بازار:
  - جفت ارز: EURUSD
  - اسپرد ماکس: ۲ پیپ
```

سپس پنجره تایید باز می‌شود و کاربر می‌تواند ویرایش و تایید کند.

### 🏆 ۲. سیستم KPI (Performance Tracker):
هر ایجنت بر اساس معیارهای زیر ارزیابی می‌شود:

**فرمول نمره‌دهی:**
```python
score = (completed/assigned × 60) + (quality × 0.4) - (failed × 15)
```

**سطوح رتبه‌بندی:**
| نمره | رتبه | آیکون |
|---|---|---|
| ۹۰-۱۰۰ | عالی | 🏆 |
| ۷۵-۸۹ | خیلی خوب | 🥇 |
| ۶۰-۷۴ | خوب | 🥈 |
| ۱-۵۹ | ضعیف | ⚠️ |
| ۰ | بدون وظیفه | ⚪ |

### ⚠️ ۳. سیستم مدیریت اعضای ضعیف:
اگر ایجنتی نمره زیر ۷۵ گرفت، پنجره‌ای باز می‌شود که ۳ گزینه دارد:
- 🔥 **اخراج و جایگزینی:** با مدل پیشرفته‌تر
- 🔄 **تغییر وظیفه:** به یک کار ساده‌تر
- 👀 **چشم‌پوشی:** برای این پروژه

### 🔁 ۴. حلقه تست خودکار (Auto-Debug Loop):
سیستم تا ۴ دور تست را تکرار می‌کند:
1. **دور اول:** کامپایل اولیه → اگر ارور، ارجاع به Codex
2. **دور دوم:** رفع ارور و اجرای بک‌تست → بررسی دراودان
3. **دور سوم:** بهینه‌سازی پارامترها توسط DeepSeek
4. **دور چهارم:** تست نهایی با Profit Factor مطلوب

**معیارهای موفقیت:**
- Profit Factor ≥ 1.5
- Win Rate ≥ 55%
- Drawdown ≤ 15%

### 🔄 ۵. Fallback System (سیستم جایگزینی):
اگر AI اصلی اعتبارش تمام شود، به صورت خودکار به ترتیب زیر جایگزین می‌شود:
- ChatGPT → Claude → DeepSeek → Grok
- Claude → ChatGPT → DeepSeek
- Codex → Claude → DeepSeek

## ۸. چالش‌ها و راه‌حل‌ها

### 🐛 چالش ۱: کرش شدن برنامه هنگام باز شدن
**علت:** فراموش شدن تابع `get_tool_config` در ConfigManager
**راه‌حل:** اضافه کردن متد کامل:
```python
def get_tool_config(self, tool_id: str) -> dict:
    return self.config.get("tools", {}).get(tool_id, {})
```

### 🐛 چالش ۲: کشیدگی زیاد باکس‌ها
**علت:** استفاده از Layout بدون تنظیم Alignment
**راه‌حل:**
```python
self.tools_grid.setAlignment(Qt.AlignTop | Qt.AlignLeft)
widget.setFixedSize(315, 115)
```

### 🐛 چالش ۳: فایل‌ها ساخته نمی‌شدند (فقط شبیه‌سازی بود)
**علت:** پایپ‌لاین فقط `time.sleep` می‌کرد
**راه‌حل:** افزودن کد واقعی تولید فایل:
```python
os.makedirs(os.path.join(project_path, "src"), exist_ok=True)
with open(mq5_path, 'w', encoding='utf-8') as f:
    f.write(mql5_code)
```

### 🐛 چالش ۴: نمایش نامرتب متن راهنما
**علت:** استفاده از HTML و تغییر جهت متن
**راه‌حل:** بازگشت به متن خام Plain Text با فرمت ساده:
```python
msg.setText(self.tool_config.get("help_text"))
msg.setIcon(QMessageBox.Information)
```

### 🐛 چالش ۵: توقف پایپ‌لاین برای دریافت ورودی از کاربر
**علت:** GUI و Thread همزمان اجرا می‌شدند
**راه‌حل:** استفاده از `threading.Event`:
```python
self.pause_event = threading.Event()
self.pause_event.clear()
self.request_prompt_approval.emit(orig, enhanced)
self.pause_event.wait()  # ترد اینجا متوقف می‌شود
```
